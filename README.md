# SingleScripts

This repository is for small useful scripts for Blender.

Currently following scripts are used:
- `InvertWeights.py`
- `LoopToolsInContextMenu`

### InvertWeights
This small function brings a missing the _invert_ functionality in **Weight Painting** mode and assigns a shortcut <kbd>X</kbd>.

This a common shortcut through out the Blender, which nearly always corresponds to _invert_ in whichever context. For instance, in **Texture Painting** workspace, <kbd>X</kbd> inverts the current colour, say from _Black to _White_ and vice versa.

### LoopToolsInContextMenu
Adds some new built-in Loop Tools operators to the Context Menu, so that they are available in place, on demand, without needing to go to main menu _Mesh_ and search them in _Transform_ submenu--available only in **Edit Mode**.

The LoopTools extension has been probably the most downloaded addon. If the extension is installed, the operators are available in the Context Menu.

Unfortunately, this is not the case with built-in operators. It's hard to understand the devs' decision on that.
